# ResolveIT

ResolveIT is a web-based IT service desk and asset management system built with C# and ASP.NET Core.

## Problem

Technical support requests are often submitted through scattered emails or messages, making them difficult to assign, monitor and resolve. ResolveIT provides one structured system for recording requests, tracking progress and maintaining a clear support history.

## Planned Users

- Requester: submits and monitors support tickets.
- Support Agent: receives, assigns and resolves tickets.
- Administrator: manages users, categories, assets and reporting.

## Minimum Viable Product

- Create and view support tickets.
- Assign ticket categories and priorities.
- Track ticket status.
- Assign tickets to support agents.
- Add comments and resolution notes.
- Search and filter tickets.
- Store information in a relational database.
- Display a basic support dashboard.

## Planned Technology Stack

- C#
- .NET 10
- ASP.NET Core MVC
- Razor views
- Entity Framework Core
- SQL Server
- HTML, CSS and JavaScript
- Git and GitHub
- xUnit testing
